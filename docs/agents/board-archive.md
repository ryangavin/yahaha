# yahaha agent coordination board

Every agent working on yahaha reads this board first, and again before editing a shared file or opening a PR.
Only APPEND to it: add one line per entry at the bottom, and never edit or delete earlier lines.
Format: `YYYY-MM-DD HH:MM | <agent/ticket> | <KIND> | <text>`

KIND is one of:
- CLAIM: you are about to change a shared symbol or file region.
- RELEASE: you are done with a claim.
- NEED: you depend on something another area owns.
- FINDING: something others should know.
- CHANGED: a shared API or hook has landed. Give the PR number.

Shared hotspots. CLAIM before you edit any of these:
- src/engine.rs: process, transition, button, queue_*, revoice, all_off
- src/api.rs: AppCmd, AppState
- src/session.rs
- src/live.rs: the input thread
- src/launchkey.rs
- src/ui.rs
- Cargo.toml: dependencies

Integration branch: integration/m3-ui (rolling). PRs target it. Only the coordinator merges.
